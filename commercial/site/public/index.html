LOCAL BY DESIGN

Three steps.
Then just glance.

Set up the collector once, pair your device agents, then connect Glimdock to that central address.

Follow the setup guide
  1. 1

    Start the central collector

    Run the Rust server on Linux or macOS. Open its web interface on localhost; pair collector keys when accessing it remotely.

  2. 2

    Pair your devices

    Create a one-time key in Nodes and run the Rust agent on your computer or adapter. It sends readings and receives its node identity automatically. Add Moonraker as a polling feed.

  3. 3

    Pair the display

    Power Glimdock over USB-C, connect to 2.4 GHz Wi-Fi, and save the collector address and display key. Its node list comes from the collector.

A FEW USEFUL ANSWERS

Before it reaches your desk.

What does Glimdock need to work?

USB power, 2.4 GHz Wi-Fi, and one central Rust collector on Linux or macOS. Native device agents support Windows, macOS and Linux; SNMP or JSON API agents cover other devices. Klipper needs Moonraker reachable from the collector. Pair native agents in the collector’s Nodes view, then connect the display to the collector. Devices need outbound access to the collector, with no incoming agent port.

Do I need Proxmox?

No. A Mac, a regular Linux machine or another supported node can be your first device. Proxmox is one node type with additional guest, storage and hardware telemetry. The collector host can be included as a generic server or omitted from the display.

Which readings can I see?

Computers expose CPU, memory, uptime, storage, network and platform-specific values where available. Routers depend on their SNMP tables or APIs. Proxmox adds guests, pools, disk health and GPUs where configured; real guest memory can require guest-agent probes. Klipper shows print progress and heater temperatures. Unsupported readings remain unavailable and stale readings are labelled.

Can I update Glimdock from the browser?

Yes. The collector’s Display & firmware view includes a USB updater for Chrome or Edge on HTTPS or localhost. It targets the Waveshare ESP32-S3-Touch-LCD-2.8 V1, verifies the image set and retains saved pairing. Use a USB data cable. V2 support and the complete printed case assembly are not yet validated.

Is there a subscription or cloud account?

No. The monitoring software is open source, and your readings stay on your local network. You don’t need a Glimdock cloud account. Checkout and this website are separate from your local monitoring.

Can I use a Flipper Zero as a companion screen?

Yes, with matching current Glimdock firmware and the native Flipper app built from the same source revision. The optional paired Bluetooth connection carries System, Alerts, Agents and Printer pages. It needs a nearby Glimdock display; the Flipper is separate hardware. The website installer includes this integration in firmware v0.5.7; build the matching Flipper app separately. Read the setup and availability notes.

Can it control my server or printer?

Glimdock monitors your setup. It does not start or stop VMs or start, pause or cancel prints. Node management changes what the collector monitors.

Can I order an assembled Glimdock now?

Paid checkout is closed. You can register unpaid interest and confirm your email to hear about availability. This creates no payment, order or reservation. The planned monitor price of approximately €99 plus shipping is an estimate; any future offer will state its price and delivery terms before you decide.

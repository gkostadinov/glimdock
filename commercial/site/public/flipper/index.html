FAST BUTTONS. HONEST FRESHNESS.

Keep browsing.
Even between connections.

After the initial registry arrives, changing nodes happens locally. Glimdock refreshes the selected node’s details in the background.

A small cache, in RAM.

The app holds summaries for up to eight active nodes and previously received detail pages. You can browse those pages while Bluetooth is disconnected. Closing the app clears its cache.

The age keeps advancing.

Cached data retains its original source age. LIVE, SUMMARY, CACHED, LOADING, STALE, NO UPDATES, DISCONNECTED and DEMO labels keep the state visible. Repeated packets do not make old samples fresh.

Your selection stays yours.

Rapid button presses select the latest target. Arriving details refresh the appropriate node without moving your focus. A page with no cached details identifies the selected node while it loads.

BUILD & PAIR

One app.
One local pairing.

Use firmware and app from the same release.

The Flipper app and Glimdock firmware must come from the same source revision. The website installer now supplies firmware v0.5.7 with this integration. Build the Flipper app from the v0.5.7 source revision. There is no ready-to-install Flipper download offered here.

  1. 1

    Install firmware v0.5.7 and build its companion

    Use the current Glimdock firmware instructions and companion build guide. Check the firmware installed on your Flipper before choosing its SDK. The default app build targets official 1.5.1; Momentum mntm-012 has a separate matching build.

  2. 2

    Install and open the native app

    Copy the matching glimdock.fap to SD Card/apps/Tools with qFlipper, or use the inspected upload helper in the source guide. Open Applications → Tools → Glimdock. USB installs the app; the status connection uses Bluetooth.

  3. 3

    Pair from your Glimdock display

    Disconnect Flipper’s phone companion. On Glimdock open Settings → Flipper Bluetooth screen → Pair / reconnect Flipper. Enter the six-digit PIN shown on Flipper. Sharing starts disabled; pairing is an explicit action.

  4. 4

    Leave the app open and browse

    Keep the app open to receive updates. Glimdock remembers the pairing for later reconnection. Short Back disconnects and exits, restoring Flipper’s normal Bluetooth profile. Use Forget Flipper on Glimdock to remove the pairing.

Build the app from the repository root

# Official Flipper firmware 1.5.1
python3 integrations/flipper/build.py --test
python3 integrations/flipper/build.py

# Matching Momentum mntm-012 build
python3 integrations/flipper/build.py --momentum mntm-012

The helper stages the source, uses an isolated SDK and writes the FAP with a build manifest. It does not upload an app or flash either device. Follow the complete guide for outputs, version checks and installation.

Tested on hardware.
Clear about the scope.

Pairing, six-node browsing, offline page navigation, background details and saved-pair reconnect were physically validated on a Waveshare ESP32-S3-Touch-LCD-2.8 V1 with Flipper Momentum mntm-012 on 17 October 2026. All 16 offline navigation checks passed; Wi-Fi remained connected during the test.

Software checks cover registries with up to eight nodes. Both the Momentum mntm-012 and official Flipper 1.5.1 app builds pass. The official 1.5.1 build’s hardware behavior has not been validated by these tests. Other custom firmware needs a compatible SDK and is not covered by this validation.

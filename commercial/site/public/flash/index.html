A little help, if you need it.

Which browsers work?

Use desktop Chrome or Edge. Web Serial is required, so Safari, Firefox, mobile browsers and some embedded browsers cannot install firmware here. Open glimdock.com/flash/ directly in a supported browser.

My board does not appear in the port chooser.

Try a USB data cable, reconnect the board and close any serial monitor using its port. Some USB-to-serial adapters need their vendor driver. If the board still cannot enter its bootloader, follow the board recovery instructions.

Will this erase my settings?

The installer updates only the verified firmware segments. The saved-settings partition is excluded, so existing Wi-Fi, collector pairing, appearance and volume preferences are retained. A brand-new board opens setup after installation.

Can I flash a different ESP32 board?

This firmware supports only the Waveshare ESP32-S3-Touch-LCD-2.8 V1 with ST7789 display and CST328 touch. The installer checks for ESP32-S3 and sufficient flash, but cannot identify every board’s display hardware. Confirm the model before proceeding. V2 is not supported.

What happens after installation?

The display restarts. New boards need 2.4 GHz Wi-Fi and a Glimdock collector address and display key. You can enter them on the touchscreen. Follow the setup guide to run a collector and pair your devices.

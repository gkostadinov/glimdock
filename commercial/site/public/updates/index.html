FIRMWARE / v0.5.7

Steadier connections. Simple power controls.

This firmware release fixes Bluetooth scan cleanup behind a captured reboot, bounds stalled HTTP responses and retries dropped Wi-Fi connections with backoff. Hold the Power button for two seconds, then release to turn off, or use Settings → Turn off Glimdock. Press the Power button to wake. Saved settings are retained.

FLIPPER ZERO / CURRENT SOURCE

Your lab status, on Flipper Zero.

The native companion receives System, Alerts, Agents and Printer pages over paired Bluetooth LE. Browse summaries for up to eight active nodes instantly, including offline; previously received details stay in RAM and retain their source age. Left/Right changes pages and Up/Down changes nodes.

Pairing, six-node browsing, offline navigation and saved-pair reconnect were physically tested on Waveshare V1 with Momentum mntm-012. The official Flipper 1.5.1 app also builds; hardware validation for that build is still pending. Build the Glimdock firmware and Flipper app from the same source revision. The Glimdock Bluetooth integration is included in firmware v0.5.7. Build the matching Flipper app separately.

STORAGE / v0.5.6

Separate temperature limits for NVMe.

NVMe temperature warnings start at 60°C, with critical alerts from 70°C. HDD and SATA limits remain at 50°C and 60°C. Configure each pair independently in the collector; hardware alarms and SMART failures retain their own alerts.

NAVIGATION / v0.5.5

Alerts open the right view.

Tap an overview alert or a disconnected-feed banner to open Health & sources. A subnode summary opens Subnodes. The banner follows its message even when a node has connected subnodes. Health puts alerts and source diagnostics ahead of device details and subnodes.

NATIVE macOS / v0.5.4

Mac memory, with the useful context.

See used RAM alongside kernel memory pressure, compression, wired memory, reclaimable cache and swap. Intel and Apple silicon agents use native OS counters. Physical Apple silicon Macs also report CPU temperature, estimated CPU package power and native battery status. An authenticated agent inside a Proxmox macOS VM can replace its allocation reading with guest OS memory, while keeping assigned RAM and host footprint separate. App memory and available headroom are labeled estimates.

CURRENT HARDWARE SOURCE

A small fleet, with room underneath.

Four top-level cards keep the main view calm. Up to eight active nodes can include grouped children, such as a managed switch beneath a router. A Subnodes page appears only when children exist; each child retains its own measurements and freshness.

CURRENT DISPLAY SOURCE

Readable, responsive and quieter.

White/dark themes, improved padding, swipe-cancels-tap behavior, a clock view and saved display settings. Brief notices accompany connection, new real alerts and observed print completion. Set sound volume from 0–100% or mute it.

OPTIONAL BOARD FEATURE

Battery voltage, without false precision.

A supported attached 3.7 V LiPo is shown as approximate voltage and broad bands, not a charge percentage or remaining runtime. A confirmed low-voltage episode gets one brief notice and sound, then remains quiet until recovery. The current printed enclosure is USB-powered.

CURRENT FIRMWARE + API

Agent operations, with an open contract.

Systems, tasks, waiting states, queues, locks, source freshness and reported usage in the native four-tab workspace. Use the Agents / Nodes button to switch workspaces. The Rust collector accepts a publisher URL or snapshot file; JSON Schema and OpenAPI support independent integrations.

Current enclosure and fit notes ↗

Private conversations, on the physical display.

Open a task and tap Open conversation to review only its linked chats, then return to the same task with Back. Chats open at the newest message with earlier history above.

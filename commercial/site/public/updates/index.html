NATIVE macOS / v0.5.4

Mac memory, with the useful context.

See used RAM alongside kernel memory pressure, compression, wired memory, reclaimable cache and swap. Intel and Apple silicon agents use native OS counters. Physical Apple silicon Macs also report CPU temperature, estimated CPU package power and native battery status. An authenticated agent inside a Proxmox macOS VM can replace its allocation reading with guest OS memory, while keeping assigned RAM and host footprint separate. App memory and available headroom are labeled estimates.

CURRENT HARDWARE SOURCE

A small fleet, with room underneath.

Four top-level cards keep the main view calm. Up to eight active nodes can include grouped children, such as a managed switch beneath a router. A Subnodes page appears only when children exist; each child retains its own measurements and freshness.

CURRENT DISPLAY SOURCE

Readable, responsive and quieter.

White/dark themes, improved padding, swipe-cancels-tap behavior, a clock view and saved display settings. Brief notices accompany connection, new real alerts and observed print completion. Set sound volume from 0–100% or mute it.

OPTIONAL BOARD FEATURE

Battery voltage, without false precision.

A supported attached 3.7 V LiPo is shown as approximate voltage and broad bands, not a charge percentage or remaining runtime. A confirmed low-voltage episode gets one brief notice and sound, then remains quiet until recovery. The current printed enclosure is USB-powered.

CURRENT FIRMWARE + API

Agent operations, with an open contract.

Systems, tasks, waiting states, queues, locks, source freshness and reported usage in the native four-tab workspace. Use the Agents / Nodes button to switch workspaces. The Rust collector accepts a publisher URL or snapshot file; JSON Schema and OpenAPI support independent integrations.

CAD / PHYSICAL VALIDATION

Pebble keeps evolving.

The current fitted CAD uses a clean native board USB opening and continuous white cradle. The revised print approach changes supports and orientation; it is not proof of a successful assembled product.

Current enclosure and fit notes ↗

Private conversations, on the physical display.

Open a task and tap Open conversation to review only its linked chats, then return to the same task with Back. Chats open at the newest message with earlier history above. The logo returns to the current workspace’s home: Agents or Nodes. Smart apostrophes and quotes render with readable punctuation on the display. The optional paired reader adds scrolling user and assistant bubbles, session and message paging, and long-message continuation. Runtime text stays outside monitoring snapshots and clears when you leave the view.

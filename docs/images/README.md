# README image provenance

The overview captures render the actual Glimdock LVGL 9.3 firmware interface
at 320×240. They use authored synthetic telemetry, marked **DEMO** on screen.
They contain no live lab snapshot, credentials or personal device address.

`glimdock-hero.webp` is a CAD visualization of the authored r7 prototype
geometry, with the same native light-theme capture on its screen. It is not a
product photograph. The enclosure still needs physical dry-fit verification.

Asset hashes and the synthetic fixture hash are recorded in `provenance.json`.
The generated images are original Glimdock project assets under the repository's
MIT license; underlying font notices remain in `LICENSES/` and `branding/`.

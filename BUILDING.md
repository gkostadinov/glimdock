# Build and verify

## Rust

Use stable Rust 1.88 or newer, a C compiler and the checked-in Cargo.lock.

```sh
cargo build --locked --release --manifest-path collector-rs/Cargo.toml
cargo test --locked --manifest-path collector-rs/Cargo.toml
collector-rs/target/release/glimdock-collector --version
collector-rs/target/release/glimdock-collector validate-config --config agent/config.example.json
```

The HTTP reader/config service are subcommands of the same binary. See `--help`
and each subcommand's `--help`. Use `collect --once` to sample without installing
services; choose an output path under a private temporary directory. Root is
needed for privileged host probes, not for unit tests.

Native Linux musl release builds:

```sh
rustup target add x86_64-unknown-linux-musl aarch64-unknown-linux-musl
cargo install cargo-zigbuild --locked
# Install Zig 0.13 or newer and put its executable on PATH.
cargo zigbuild --locked --release --manifest-path collector-rs/Cargo.toml --target x86_64-unknown-linux-musl
cargo zigbuild --locked --release --manifest-path collector-rs/Cargo.toml --target aarch64-unknown-linux-musl
```

`ring` builds a small C/assembly dependency; Zig supplies the musl linker/sysroot.
No OpenSSL dynamic library is required. CI tests the source and uploads binary
artifacts; it does not publish a GitHub release or deploy to hosts. Record the
toolchain, Cargo.lock hash and tested architecture with each distributed binary.
Ship dependency notices/lockfile inventory as well as the binary.

## Firmware and previews

Install PlatformIO, Python 3.11+ and a C/C++ compiler/CMake for native preview.
Build the firmware before running the native preview so its pinned LVGL source
is downloaded. A physical board is required for SPI color order, power latch,
touch rotation and Wi-Fi checks; framebuffer previews do not establish those.

```sh
pio run --project-dir firmware --environment homelab_s3
python3 tools/native-preview/test_gestures.py
python3 tools/native-preview/render.py --snapshot agent/demo.json --output output/native-demo
python3 -m unittest discover -s tests -v
```

The standalone browser demo is authored synthetic telemetry. It approximates the
dashboard; the native renderer compiles the actual `firmware/src/main.cpp` for
exact LVGL layout checks. Native management adapters simulate settings and never
change hardware Wi-Fi or a live collector.

## Enclosure

Create an isolated Python environment, install `enclosure/requirements.txt`, and
see `enclosure/reference/README.md` for the external V1 STEP reference. Manufacturer
drawings are not included or licensed by Glimdock. The current r7 cover includes internal USB privacy walls and 2.45 mm rear-pillar
relief. It retains the r4 separate mounting yoke. To reproduce comparison geometry
from a clean checkout, run `python enclosure/build.py --legacy-r3` once, then
`python enclosure/build.py`. The first command supplies baseline geometry for
the delta check; do not print its superseded front-shell integral posts. Current
CAD exports are in `enclosure/output/internal-usb-r7/`. Only CAD is generated by
the public scripts; choose your own slicer settings. Review the keeper design
and check fit physically before fabrication. The case is a prototype;
the firmware's supported V1 board has been discontinued by its manufacturer.

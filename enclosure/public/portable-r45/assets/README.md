# Viewer renders

These images are stage-only captures of the included static viewer loading the exported r45 enclosure geometry. The display artwork is synthetic. Glass, battery and speaker volumes are illustrative primitives; no manufacturer board CAD is shown. The images show nominal CAD surfaces, not printed finish or physical validation.

- `landscape-ears.png`: landscape stand with the current 6 mm bunny ears.
- `portrait-eyes.png`: portrait stand with the interchangeable eye ornaments.

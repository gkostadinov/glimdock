# Manufacturer fitting reference

The current Pebble Landscape CAD expects the V1 manufacturer STEP at
`esp32-s3-touch-lcd-2_8.stp` here. Obtain it from the official Waveshare
resources; manufacturer geometry, personal fit files and Orca projects are
not redistributed. The authored design parameters are in
`enclosure/pebble-landscape/design.json`. Nominal CAD checks do not establish
physical fit. The current main design is USB-only.

# Historical manufacturer fitting reference

The archived r19 parametric model expects the V1 manufacturer STEP named
esp32-s3-touch-lcd-2_8.stp here. Obtain it from the official Waveshare resources;
manufacturer geometry and personal printer-linked projects are not redistributed.

The current [Portable r45 snapshot](../public/portable-r45/README.md) provides
original direct-edit enclosure CAD and sanitized portable 3MF layouts. Its
manufacturer PCB fitting references and printer connections are excluded.
The earlier parametric parameters in enclosure/pebble-landscape/design.json
are historical source, not the current portable housing. Follow the current
package's assembly and validation notes.
